# 💰 Controle de Gastos

Aplicativo web desenvolvido para controle financeiro pessoal, permitindo ao usuário registrar gastos, visualizar saldo disponível e acompanhar suas despesas por meio de gráficos interativos.

---

## 🚀 Funcionalidades

* 💵 Cadastro de salário mensal
* 📅 Seleção de mês e ano
* ➕ Adição de gastos personalizados
* 🏷️ Categorias editáveis (usuário pode criar as próprias)
* 📊 Gráfico em pizza com distribuição dos gastos
* 📉 Cálculo automático de saldo disponível
* 🏆 Identificação do maior gasto
* 🖨️ Impressão de relatório
* 📄 Exportação em PDF com gráfico
* 📱 Suporte a PWA (instalável no celular)

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Chart.js (gráficos)
* jsPDF (exportação PDF)
* html2canvas (captura de gráfico)

## 📦 Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/controle-de-gastos.git
```

2. Acesse a pasta:

```bash
cd controle-de-gastos
```

3. Abra o arquivo:

```bash
index.html
```

Ou utilize o Live Server no VS Code.

---

## 📱 Instalação como App (PWA)

* Abra o site no navegador
* Clique em **"Instalar App"** (ou menu do navegador)
* O app será instalado no seu dispositivo
